# Accessible Design Co.

A simple responsive website for a fictional design company focused on creating accessible and inclusive digital experiences.

The site includes an introduction to the company, a services section, and a contact form. I also made sure the site is keyboard-friendly, responsive on different screens, and uses accessible color contrast.

## How to Run

No special setup is needed.

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in a web browser.

If you're using VS Code, you can also use the **Live Server** extension and open the site through the local server.
